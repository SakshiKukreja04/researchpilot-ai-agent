# AI usage disclosure

This prototype was developed with AI-assisted implementation and review in
VS Code using Copilot SDK. Assistance covered repository inspection, code
generation/refactoring suggestions, test analysis, and documentation drafting.

Human work includes choosing the architecture and requirements, configuring
the local Python environment and Groq account, reviewing generated changes,
running tests and live evaluations, checking sources, and deciding which
behavior is acceptable for the prototype.

No live evaluation result should be considered valid unless it was generated
by the application and recorded after reviewing the corresponding run.
